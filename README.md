# Dashboard_Super_Ensino
This dashboard was developed using Power BI Desktop for a company in Manaus focused on the education of elementary school students. The data was managed through Postgres, processed via Pentaho Data Integration, and then loaded into another Postgres repository with a multidimensional model. Afterward, this data was consumed by the dashboard, where a series of changes were made regarding rules, filters, and calculations. Additionally, the charts were modified to provide more intuitive and transparent visibility of the information.
